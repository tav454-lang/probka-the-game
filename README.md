# Тянучки

Головоломка для iPhone: тяни цветные блоки пальцем к воротам своего цвета и очисти поле. 500 уровней с боссами, глазастые блоки, стены, стрелки, лёд, двойные блоки, ключи и замки, тайные блоки, бомбы, таймер, помощники, подарок дня, серия побед и магазин оформлений.

Играть: https://tav454-lang.github.io/probka-the-game/

На айфоне открой ссылку в Safari → «Поделиться» → «На экран „Домой“». После первого запуска игра работает без интернета, прогресс хранится на телефоне.
