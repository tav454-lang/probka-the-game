# Тянучки

Головоломка для iPhone: тяни цветные блоки пальцем к воротам своего цвета и очисти поле. 300 уровней, стены, стрелки, лёд, двойные блоки, таймер и помощники.

Играть: https://tav454-lang.github.io/probka-the-game/

На айфоне открой ссылку в Safari → «Поделиться» → «На экран „Домой“». После первого запуска игра работает без интернета, прогресс хранится на телефоне.
