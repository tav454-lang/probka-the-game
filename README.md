# Тянучки · 9.0 «Ателье»

Мобильная веб-головоломка для iPhone: тяни цветные блоки к воротам своего цвета. Это веб-игра/PWA, не нативное приложение iOS.

Играть: https://tav454-lang.github.io/probka-the-game/

## Что изменилось

Вся кампания пересобрана: 650 уровней, включая 500 переработанных и 150 дополнительных. Плотные поля и больше перестановок перед освобождением проходов; обучение механикам, боссы, стрелки, лёд, двойные блоки, ключи, скрытые цвета и бомбы сохранены. Сложность создаётся планированием, время рассчитано с запасом. Таймер стартует после первого движения.

Новая палитра «Ателье», кремовые панели, лиловые акценты, объёмная эмаль блоков, световой блик при перетаскивании и подсветка подходящих ворот. Прежние оформления, переключатель глазок, магазин, бесконечный режим и девять авторских музыкальных треков сохранены.

Генератор записывает полный путь решения и воспроизводит его по игровым правилам до принятия уровня. Проверяются доступность перемещений, ворота, лёд, ключи и таймеры бомб. Сертификаты кампании лежат отдельно в `tests/campaign-proofs.json`, не загружаются телефоном и не раскрывают решения в интерфейсе. `d` — найденная оценка числа перестановок, не гарантия оптимального решения.

## Сохранение

Старый ключ `tyanuchki-save` и формат кодов TYN1 сохранены. Число завершённых уровней `reached` не уменьшается при обновлениях, повторном прохождении и изменении состава кампании. После 120 пройденных уровней следующим будет 121-й.

Сохранение происходит после победы и при уходе со страницы. Основная запись дополнена резервной записью, отдельным счётчиком и копией в IndexedDB. При повреждении основной записи игра восстанавливает доступный прогресс. Если браузер запрещает запись, появляется сообщение с предложением скопировать код сохранения.

Прогресс локальный для устройства и контекста браузера; автоматической синхронизации между устройствами нет. Очистка данных сайта удаляет и резервные копии. Код из меню «Сохранение» позволяет перенести прогресс вручную.

## Запуск

Открой ссылку выше в Safari → «Поделиться» → «На экран “Домой”». После первой полной загрузки игра работает без интернета. Для получения версии 9.0 открой игру с интернетом; если ещё видна старая версия, полностью закрой и открой её снова. Адрес сайта оставлен прежним.

Для локальной разработки из папки проекта: `python3 -m http.server 8000`, затем http://localhost:8000 . Сохранение локального запуска отдельно от опубликованной игры.

## Проверки

`node scripts/test-campaign.cjs` — полное прохождение всех 650 сертификатов двумя копиями движка (игра и генератор), контроль столкновений, замков, льда, ворот и бомб без помощников.

`node scripts/test-progress.cjs` — перенос старого сохранения, перезагрузка, монотонный счётчик, повреждение основной записи, резервная копия, IndexedDB, несколько вкладок и недоступное хранилище.

Дополнительная проверка браузера: установи Playwright и Chromium, затем `node scripts/test-browser.cjs` (либо задай `CHROMIUM_PATH` для своего Chromium). Проверяются ширины 320/375/390/430 px, прохождение уровней 1/25/150/325/650 событиями сенсорного указателя и восстановление прогресса после перезагрузки.

Для воспроизводимой пересборки: `node scripts/rebuild.cjs 0 100`, затем диапазоны `100 300`, `300 500`, `500 650`; после их завершения `node scripts/assemble.cjs`. Временные файлы `rebuilt-*.json` исключены из Git. Полная пересборка требует времени и не выполняется на iPhone.

Остаётся ручная проверка на физическом iPhone: ощущения от перетаскивания, звук, вибрация, восстановление после выгрузки Safari/PWA системой и офлайн-запуск после обновления.
